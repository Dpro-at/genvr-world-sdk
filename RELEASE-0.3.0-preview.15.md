# 0.3.0-preview.15

World moves into Build, and motions can be shared.

Build: the World tab is gone from the top bar (Build · Items · Avatar · Filming). Its parts list now lives in the Build left dock next to Tools and Explorer (Tools · World · Explorer); the right panel shows the tool options, the picked world part or the place summary. Saved layouts from earlier versions open with World placed right after Tools. Every world agent tool (lights, start point, water, sky, weather) works as before.

Motion lab — share a motion: a motion version is first kept privately in My motions. Before sharing, the lab looks for similar motions (a library move with a close pace, stride, lean and step height, run on the same course for slide and score) so the owner can keep their own or use the library one. The share dialog shows name, description, tags, the character it was made on, score, a preview length, four rights checks and the licence: free to use in GenVR worlds and films, also commercially; credit the creator; do not sell or re-share the motion file on its own. Only motions made in the lab from a GenVR library move on a GenVR character, without a source video, that finish the course without a fall or a car hit can be shared. An agent can prepare a share; only the owner shares it, and the owner can stop sharing at any time. Without a hosting adapter the result is stated honestly as a local preview.

No method scans or uploads private libraries, voices or model weights. Local storage keys, project and library IDs and voice assignments are unchanged; older projects and layouts open as before.

Validation: 68 SDK tests across 16 files, 155 web tests, 100 film tests, Studio type checking and build, and an archive audit for private assets and local configuration.
